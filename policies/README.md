# Kiwi Market — shop policies (fictional)

**Kiwi Market is a fictional online shop invented for this project.** These policies exist only to demonstrate
retrieval-augmented generation (RAG): the assistant answers with facts from these files instead of guessing.
Any similarity to a real company is coincidental. The `.example` domain is reserved for documentation (RFC 2606).

Each `##` section of the policy files is one retrievable chunk.

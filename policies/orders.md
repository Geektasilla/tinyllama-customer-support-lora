# Orders

## Cancelling an order
An order can be cancelled free of charge within 2 hours after it was placed.
Go to My Account → Orders, open the order and click "Cancel order".
After 2 hours the order is already being packed and can no longer be cancelled.
In that case, accept the delivery and send the items back as a return (see Returns).

## Changing an order or the delivery address
Items, quantities and the delivery address can be changed until the order is shipped.
Go to My Account → Orders → "Edit order".
Once the order is shipped, the address can only be changed with the carrier using the tracking link.

## Order confirmation
An order confirmation email is sent within 15 minutes after the order is placed.
If it does not arrive, check the spam folder or contact Customer Support.
